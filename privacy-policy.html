Política de privacidad

Aplicación: Privacidad y seguridad (Servicio de Seguridad)

Última actualización: 13 de agosto de 2026

Esta política explica qué información puede consultar la aplicación, para qué se utiliza y qué ocurre con ella. La aplicación está diseñada para realizar comprobaciones de seguridad del dispositivo y mostrar los resultados al usuario.

1. Información que la aplicación consulta

Para realizar sus funciones, la aplicación puede consultar información técnica y de seguridad disponible localmente en el dispositivo, como modelo y fabricante, versión de Android, nivel/parche de seguridad, estado de batería, almacenamiento, memoria RAM, conectividad, estado del bloqueo de pantalla, opciones de desarrollador, depuración USB, instalación desde fuentes externas y permiso de notificaciones.

También puede revisar la lista de aplicaciones instaladas y determinados permisos concedidos a esas aplicaciones (por ejemplo, cámara, ubicación, micrófono y contactos) para calcular indicadores de riesgo. La aplicación no necesita leer el contenido de esas aplicaciones.

2. Contacto de emergencia

Si el usuario utiliza la función de contacto de emergencia, el nombre y número introducidos se utilizan para esa función y se almacenan localmente en el dispositivo mientras el usuario los conserve. No se venden ni se utilizan para publicidad.

3. Notificaciones

La aplicación puede solicitar permiso para enviar notificaciones. Las notificaciones se utilizan para avisos relacionados con el estado o las comprobaciones de seguridad. El usuario puede revocar este permiso desde los ajustes de Android.

4. Servicios de terceros

La versión actual del proyecto incluye componentes de Firebase/Google para determinadas funciones. Cuando una función que utilice esos componentes se ejecuta, la información necesaria para prestar dicha función puede ser procesada por esos servicios conforme a sus propias políticas. La aplicación no utiliza esos servicios para vender datos personales ni para publicidad dirigida.

Para más información, consulta las políticas de privacidad de los proveedores de dichos servicios.

5. Internet y transmisión de datos

Las comprobaciones básicas de seguridad y la información del dispositivo se procesan principalmente en el propio dispositivo. No obstante, las funciones que dependan de servicios en línea pueden requerir conexión a Internet y transmitir la información estrictamente necesaria para esa función.

6. Publicidad, ventas y compras

La aplicación no contiene anuncios y no vende información personal. La versión actual no está diseñada para realizar compras dentro de la aplicación ni suscripciones.

7. Conservación y eliminación

Los datos que la aplicación guarda localmente permanecen en el dispositivo hasta que el usuario los modifique, elimine los datos de la aplicación o desinstale la aplicación. Los datos procesados por servicios de terceros están sujetos también a las políticas de conservación de esos proveedores.

8. Seguridad

Se aplican medidas razonables para limitar el acceso a la información tratada por la aplicación. Ningún sistema puede garantizar seguridad absoluta.

9. Privacidad de menores

La aplicación no está dirigida específicamente a menores de edad y no solicita deliberadamente información personal de menores.

10. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, sus dependencias o los requisitos legales. La fecha de actualización se modificará cuando corresponda.
